- 右侧第三块“面试工作区”展开后不再无限变长。
- 第三块整体高度固定，内容较多时在块内滚动。

- `patchwork-recruit-gpt/interview-center.html`

## 智联简历自动导入失败重试修复

### 问题
- 24h 自动处理后，智联下载目录中部分 PDF 已经落盘，但简历库统计和入库结果看起来不一致。
- 排查发现 `尤法洋_短视频方向_zhilian_20260617.pdf` 文件约 10.7MB，旧的 PDF 文本兜底解析会触发 `Maximum call stack size exceeded`。
- 旧逻辑失败后没有把失败状态写入智联导入 manifest，也没有失败冷却和重试上限，导致该坏文件每隔几分钟被重新排队，污染 batch 统计并影响观察。

### 修改
- `patchwork-recruit-gpt/server/legacy-parts/server.part000.js`
  - 新增导入失败重试上限、失败冷却时间、PDF 文本解析大小限制等常量。
- `patchwork-recruit-gpt/server/legacy-parts/server.part003.js`
  - 对 PDF 文本兜底解析加 source/stream/总字符数限制。
  - 单个 PDF source 解析异常时记录日志并跳过，避免大文件触发栈溢出拖垮导入任务。
  - batch 解析失败时调用失败 manifest 记录逻辑。
- `patchwork-recruit-gpt/server/legacy-parts/server.part004.js`
  - 新增失败文件 manifest 记录，保存 `retryCount`、`failedAt`、`lastError`。
  - 扫描智联/51/BOSS 简历目录时跳过冷却中或超过重试上限的失败文件。
  - 兼容历史 batch failed 记录，即使旧版本没有写 manifest，也能根据历史失败次数跳过同一 hash。
  - 取消 batch job 时同时清理 `pending` 和 `parsing`，避免中断后永久卡在处理中。
